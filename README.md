# Q-Pixelate

Windows 长视频局部打码工具。在源视频时间轴上选取片段，设置全屏模糊、区域模糊、贴纸遮挡或片段变速，只重编码必要的关键帧范围，再与原视频其余部分拼接。

## 启动

Windows x64 安装版使用 `Q-Pixelate-Setup.exe`，可以分别选择程序目录和组件目录。安装后，在「设置 → 环境与组件」查看与更改位置。更改组件位置会暂时关闭编辑器，验证新目录可用后再切换。配套 ZIP 可以保存在安装包旁，以便离线安装。

Windows x64 便携版直接用 `Q-Pixelate.exe` 启动。首次运行会检测基础编辑器环境与 FFmpeg，缺失时可选择「下载安装所选项」或导入发行清单对应的离线组件包。可以在「设置 → 环境与组件」查看版本和占用、重新检测、安装、修复或卸载。便携版默认把组件放在发行目录的 `components` 下。迁移工程时，还需保留源视频和贴纸的相对路径。

从源码开发时，双击 `launch.bat`，或在项目目录运行：

```powershell
python -m pip install -r requirements.txt
python -m q_pixelate
```

需要 Python 3.12+、PySide6 6.8+、系统 PATH 中的 `ffmpeg` 和 `ffprobe`。本机已有所需环境，不必重复安装。可把视频拖进窗口，也可使用 `python -m q_pixelate "D:\Videos\录屏.mp4"` 打开文件。

使用 Python 3.12 x64 和 PyInstaller 构建 Windows 启动器及可离线导入的组件包：

```powershell
python scripts/build_portable.py
```

默认输出至 `dist/portable`。发行时传入 `--base-url` 指向存放组件 ZIP 的下载目录，将 `Q-Pixelate.exe` 与生成的 `component-catalog.json` 一同分发。启动器也可直接从同目录的配套 ZIP 安装，无需联网。源码版可在启动前将 `QPIXELATE_HOME` 设为该目录，使用同一份组件清单和已安装组件。

## 使用

1. 打开视频。**播放轨**用左键点击和拖动来定位。**选区轨**用左键拖动未锁定选区的端点或内部来调整范围，选区操作不会改变播放位置。空格切换播放／暂停。
2. **← / →** 逐帧后退／前进。**Shift + ← / →** 快退／快进 N 秒，N 在播放按钮旁设置，默认 5 秒。长按方向键超过 300 ms 后以 **3×** 预览，松开暂停。
3. 在选区轨 **按住右键拖动，松开创建选区**。拖动范围会扣除已有选区，剩下的连续时间各成一段。也可在「选区」页使用 **I / O** 或输入时间后点击 **添加选区**。在同一页可设置 **0.25–4×** 片段速度。
4. 将播放位置移到可编辑的选区。从「贴纸素材」把缩略图拖到视频画面，每次添加一层，从播放位置开始持续 **2 秒**，到选区末尾时截断。可导入多张图片，PNG 保留透明度，素材库会保留导入的副本。
5. 在「图层属性」选择方框、椭圆或套索，点击 **绘制遮罩** 后在画面拖动。新遮罩默认用于模糊。可从素材库点选图片，再回到图层属性点击 **使用素材库选中的贴纸**，或将遮罩用途切换为贴纸。给已有贴纸裁剪时，选中该层并点击 **绘制 / 重绘本层遮罩**。通过 **变换对象** 分别调整贴纸和遮罩。
6. 点击图层轨的条目选中图层，拖动内部移动时间，拖动两端调时长。图层属性可输入时间、重命名、改变叠放顺序和删除。**Ctrl+T** 打开自由变换，框内移动、控制点缩放、框外旋转，按住 **Shift** 等比缩放。**Enter** 提交变换，**Esc** 撤销本次变换。
7. 切换选区会保留图层草稿。保存或导出前，选择带 `*` 的选区，点击 **确认并锁定片段**。再次修改时点击 **解锁并编辑**。
8. 缩放后拖动下方滚动条，或用 **中键拖动 / Alt + 左键拖动** 平移时间轴。
9. 点击 **预览当前片段效果** 渲染当前草稿的全部图层、羽化和倍速，预览最高宽度 960px。编辑画布显示贴纸和遮罩轮廓。确认后点击 **缝合导出**，输出 MP4/MKV，保留源分辨率。
10. **保存工程**生成 `.qpixel` 文件，保存各层的时间、变换及相对素材路径。重新载入需要原视频和贴纸仍在。用 **载入工程** 打开旧工程时，旧效果会迁移到图层。

快捷键在编辑器的按钮、画面和时间轴获得焦点时生效；输入框编辑期间保留正常文字输入。

选中未锁定片段，打开「自动打码」并点击「识别裸露内容」。首次使用先在「设置 → 环境与组件」安装 CPU 或 NVIDIA 识别环境及一个 NudeNet 模型。点击检测结果可跳转，画面显示候选框。取消勾选误报后，点击「全部马赛克」生成可编辑图层。可在「图层属性」调整时间、位置、大小和像素块，再用「预览当前片段效果」检查实际效果。已应用图层可随工程保存，卸载识别组件后仍可预览和导出。

扫描和推理全程在本机执行。快速扫描默认每秒分析约 6 帧，可能错过一闪而过的画面。逐帧扫描可提高时间覆盖，识别结果仍需人工复核，尤其是游戏和动画素材。自动打码沿用下文的固定帧率快速导出约束。

## 快速导出的范围

- 已实现并测试：H.264、8-bit 4:2:0 SDR、逐行、从零开始的固定帧率录屏，MP4/MKV 输入，MP4/MKV 输出。
- 支持有 B 帧、整数或常见小数帧率、无音轨和多音轨。视频尺寸必须为偶数。
- 首版不保证 H.265/AV1、HDR/10-bit、可变帧率、隔行、旋转或异常时间戳；不支持时明确报错，不会悄悄对整片重新编码。
- 输出保留第一条实际视频轨和全部兼容音轨及其语言信息；不保留字幕、封面、附件和章节。MP4 不兼容的音轨会提示改用 MKV。
- 所选效果按左闭右开的时间区间生效，时间精度受视频帧率限制。编码范围向外扩展至关键帧，范围相交时合并；这些边界范围也会重编码，其余视频流直接复制。
- 没有倍速变化时音轨直接复制。有倍速变化时，按相同的源时间范围对全部音轨变速并编码为 AAC，保持音高和音画同步，保留延迟音轨的起始静音；音频会发生一次有损编码。片段输出时长按帧取整，误差不超过约一帧。
- 重编码部分使用 libx264、CRF 18，存在一次有损编码。整片仍需要磁盘读写，源文件很大时合并也需要时间。
- MP4 使用 `avc3` 样本类型，以容纳拼接点的 H.264 参数集更新；在 FFmpeg/Qt 中验证播放，目标网站或旧播放器的兼容性还需实际确认。
- 输出磁盘需预留约源视频 **2.2 倍**（慢放可能需要更多）的可用空间作为片段和成片临时存储。临时文件只在本次任务目录内创建和清理。

源视频不覆盖。导出失败或取消时不交付半成品，已有目标文件会保留至新成片通过检查后才被替换。

## 验证

```powershell
python -m unittest discover -s tests -v
python -m compileall -q q_pixelate
```

测试的图像断言额外使用 Pillow（本机已安装）：`python -m pip install Pillow`。集成测试会用 FFmpeg 自动生成小型视频，核对实际解码帧数、未修改片段逐帧哈希、原始音频、模糊范围、图片遮挡、工程和取消行为。详见 `docs/verification.md`。
