# Q-Pixelate

Windows 长视频局部打码工具。在源视频时间轴上选取片段，设置全屏模糊、固定区域模糊或图片遮挡，只重编码必要的关键帧范围，再与原视频其余部分拼接。

## 启动

双击 `launch.bat`，或在项目目录运行：

```powershell
python -m pip install -r requirements.txt
python -m q_pixelate
```

需要 Python 3.12+、PySide6 6.8+、系统 PATH 中的 `ffmpeg` 和 `ffprobe`。本机已有所需环境，不必重复安装。可把视频拖进窗口，也可使用 `python -m q_pixelate "D:\Videos\录屏.mp4"` 打开文件。

这是可直接运行的首版源代码程序，尚未打包独立 exe。

## 使用

1. 打开源视频，在时间轴点击定位。空格播放/暂停，左右方向键步进定位。
2. 按 **I** 设置入点，按 **O** 设置出点；也可 **Shift 拖动** 创建选区，拖动绿色边界调整范围，或直接输入 `时:分:秒.毫秒`。缩放滑块和下方滚动条适用于长视频。
3. 选择效果，点击 **添加选区**：
   - **全屏模糊**：设置模糊强度。
   - **区域模糊**：在画面中拖出矩形；拖动内部移动，拖动右下角缩放，也可按百分比输入坐标。
   - **图片素材遮挡**：选择 PNG/JPEG 等图片，调整矩形位置和大小；PNG 保留透明度，图片按矩形拉伸。
4. 已添加的片段可从列表选择，修改参数后点击 **应用修改**。切换片段、预览、保存和导出也会应用当前选中片段的参数；非法或重叠的参数会先要求修正。各片段时间不能重叠，相邻片段可以共用边界。
5. 点击 **预览效果**，生成该短片段的实际滤镜预览并循环播放。主编辑画面显示原画及遮挡位置框；真实效果在预览窗口中播放。参数变化后需重新预览。预览最高宽度 960px，最终导出保持源分辨率。
6. 点击 **缝合导出**，选择新的 MP4/MKV 文件。进度和日志会显示任务阶段，支持取消。完成后显示重编码/直接复制的秒数，可打开输出目录。
7. **保存工程**生成 `.qpixel` 文件，保存时间范围、参数及相对路径，不复制原视频或图片。重新载入工程时需要源视频和素材仍然存在。源文件发生变化会要求重新打开。

快捷键在编辑器画面或时间轴获得焦点时生效；输入框编辑期间保持正常文字输入。

## 快速导出的范围

- 已实现并测试：H.264、8-bit 4:2:0 SDR、逐行、从零开始的固定帧率录屏，MP4/MKV 输入，MP4/MKV 输出。
- 支持有 B 帧、整数或常见小数帧率、无音轨和多音轨。视频尺寸必须为偶数。
- 首版不保证 H.265/AV1、HDR/10-bit、可变帧率、隔行、旋转或异常时间戳；不支持时明确报错，不会悄悄对整片重新编码。
- 输出保留第一条实际视频轨和全部兼容音轨及其语言信息；不保留字幕、封面、附件和章节。MP4 不兼容的音轨会提示改用 MKV。
- 所选效果按左闭右开的时间区间生效，时间精度受视频帧率限制。编码范围向外扩展至关键帧，范围相交时合并；这些边界范围也会重编码，其余视频流直接复制。
- 重编码部分使用 libx264、CRF 18，存在一次有损编码。整片仍需要磁盘读写，源文件很大时合并也需要时间。
- MP4 使用 `avc3` 样本类型，以容纳拼接点的 H.264 参数集更新；在 FFmpeg/Qt 中验证播放，目标网站或旧播放器的兼容性还需实际确认。
- 输出磁盘需预留约源视频 **2.2 倍**的可用空间作为片段和成片临时存储。临时文件只在本次任务目录内创建和清理。

源视频不覆盖。导出失败或取消时不交付半成品，已有目标文件会保留至新成片通过检查后才被替换。

## 验证

```powershell
python -m unittest discover -s tests -v
python -m compileall -q q_pixelate
```

测试的图像断言额外使用 Pillow（本机已安装）：`python -m pip install Pillow`。集成测试会用 FFmpeg 自动生成小型视频，核对实际解码帧数、未修改片段逐帧哈希、原始音频、模糊范围、图片遮挡、工程和取消行为。详见 `docs/verification.md`。
