# Q-Pixelate

Windows 长视频局部打码工具。在源视频时间轴上选取片段，设置全屏模糊、区域模糊、贴纸遮挡或片段变速，只重编码必要的关键帧范围，再与原视频其余部分拼接。

## 启动

双击 `launch.bat`，或在项目目录运行：

```powershell
python -m pip install -r requirements.txt
python -m q_pixelate
```

需要 Python 3.12+、PySide6 6.8+、系统 PATH 中的 `ffmpeg` 和 `ffprobe`。本机已有所需环境，不必重复安装。可把视频拖进窗口，也可使用 `python -m q_pixelate "D:\Videos\录屏.mp4"` 打开文件。

这是可直接运行的首版源代码程序，尚未打包独立 exe。

## 使用

1. 打开视频。时间轴**上轨用于播放定位，下轨用于选择片段**；点击上轨不会改变选区。空格仅切换播放／暂停。
2. **← / →** 逐帧后退／前进；**Shift + ← / →** 快退／快进 N 秒，N 在播放按钮旁设置，默认 5 秒。长按方向键超过 300ms 后以 **3×** 快进／快退预览，松开暂停；也有对应按钮。倒放采用静音连续定位预览，流畅度取决于解码性能。
3. 点击 **选择新片段**，用 **I / O** 设入点／出点，或在下轨 **Shift 拖动** 创建选区、拖动绿色边界、输入 `时:分:秒.毫秒`。点击 **添加选区** 创建片段并锁定长度；也可先点击 **锁定片段长度**，再设参数、添加选区。
4. 长度锁定后修改片段：
   - **全屏模糊**：设置模糊强度。
   - **区域模糊**：选择方框、圆形／椭圆或套索，在画面拖动绘制；套索松开自动闭合。点击 **重新绘制遮罩** 替换形状。方框／椭圆绘制后可内部移动、右下角缩放。**羽化范围**按原画短边百分比设置，向内部柔化边界；0 为硬边。
   - **贴纸遮挡**：可一次导入多张自制贴纸到本机素材库，再从下拉列表选取；重新启动后仍可复用。PNG 保留透明度，贴纸按矩形缩放。导入时复制素材，移动原图片不影响库内贴纸。
   - **片段速度**：支持 **0.25–4×**，可与遮挡同时使用；选择 **不遮挡（仅变速）** 可单独变速。编辑器按源视频时间定位，成片时长随倍速变化。
5. 点击底部固定的 **确认并锁定片段** 保存修改并退出该片段编辑。锁定后参数、边界和删除均受保护；再次修改先点击 **解锁并编辑**，改变范围另点 **解锁片段长度**。有未确认修改时，切换片段、保存和导出会要求先确认。片段不能重叠，相邻片段可以共用边界。
6. 缩放后拖动下方滚动条，或用 **中键拖动 / Alt + 左键拖动** 平移时间轴；浏览其他时段不会改变播放位置或选区。
7. 点击 **预览当前片段效果** 渲染当前草稿，包含遮罩、羽化、贴纸和倍速，并循环播放；预览不会自动确认片段。主画面显示原画及遮罩轮廓。参数变化后需重新预览，预览最高宽度 960px，导出保持源分辨率。
8. 确认后点击 **缝合导出**，选择新的 MP4/MKV；任务支持取消。完成后显示按源视频计算的重编码／直接复制秒数。
9. **保存工程**生成 `.qpixel` 文件，记录速度、形状、套索路径、羽化、锁定状态和相对素材路径，不复制视频或素材库。重新载入需要原视频和贴纸仍在；兼容旧工程中的图片遮挡。

快捷键在编辑器的按钮、画面和时间轴获得焦点时生效；输入框编辑期间保留正常文字输入。自动裸体检测暂不实现。

## 快速导出的范围

- 已实现并测试：H.264、8-bit 4:2:0 SDR、逐行、从零开始的固定帧率录屏，MP4/MKV 输入，MP4/MKV 输出。
- 支持有 B 帧、整数或常见小数帧率、无音轨和多音轨。视频尺寸必须为偶数。
- 首版不保证 H.265/AV1、HDR/10-bit、可变帧率、隔行、旋转或异常时间戳；不支持时明确报错，不会悄悄对整片重新编码。
- 输出保留第一条实际视频轨和全部兼容音轨及其语言信息；不保留字幕、封面、附件和章节。MP4 不兼容的音轨会提示改用 MKV。
- 所选效果按左闭右开的时间区间生效，时间精度受视频帧率限制。编码范围向外扩展至关键帧，范围相交时合并；这些边界范围也会重编码，其余视频流直接复制。
- 没有倍速变化时音轨直接复制。有倍速变化时，按相同的源时间范围对全部音轨变速并编码为 AAC，保持音高和音画同步，保留延迟音轨的起始静音；音频会发生一次有损编码。片段输出时长按帧取整，误差不超过约一帧。
- 重编码部分使用 libx264、CRF 18，存在一次有损编码。整片仍需要磁盘读写，源文件很大时合并也需要时间。
- MP4 使用 `avc3` 样本类型，以容纳拼接点的 H.264 参数集更新；在 FFmpeg/Qt 中验证播放，目标网站或旧播放器的兼容性还需实际确认。
- 输出磁盘需预留约源视频 **2.2 倍**（慢放可能需要更多）的可用空间作为片段和成片临时存储。临时文件只在本次任务目录内创建和清理。

源视频不覆盖。导出失败或取消时不交付半成品，已有目标文件会保留至新成片通过检查后才被替换。

## 验证

```powershell
python -m unittest discover -s tests -v
python -m compileall -q q_pixelate
```

测试的图像断言额外使用 Pillow（本机已安装）：`python -m pip install Pillow`。集成测试会用 FFmpeg 自动生成小型视频，核对实际解码帧数、未修改片段逐帧哈希、原始音频、模糊范围、图片遮挡、工程和取消行为。详见 `docs/verification.md`。
