# 时间轴分离与多图层编辑设计

状态：已获用户批准。

## 目标与已确认需求

播放轨只负责播放位置，选区轨只负责选区。左键修改未锁定选区端点或整体移动选区；右键按下、拖动、松开直接创建新选区，自动扣除已有选区覆盖的时间。

同一选区允许任意多个独立时长的贴纸与模糊遮罩。素材库贴纸拖到视频画面即添加，默认时长 2 秒。贴纸变形参考 PS Ctrl-T。遮罩可作为模糊范围，也可裁剪贴纸。

用户明确补充：**遮罩需要独立于贴纸移动**。贴纸变换与遮罩变换分别保存；贴纸移动、缩放、旋转不带动遮罩，反之亦然。

## 现状与约束

- `widgets.py:Timeline.mousePressEvent` 在下轨空白/内部点击以及选区锁定时走 seek 分支，导致下轨改变播放位置。Qt 模拟鼠标已复现。
- `app.py:select_edit` 自动 seek 到入点，也必须移除选区轨触发这条路径时的 seek。
- `model.py:Edit` 当前包含单个 effect/rect/image；`render.py:effect_graph` 每个选区仅合成一个效果。需要一起升级，不能只增加界面条目。
- 沿用 Python、PySide6、FFmpeg、本地素材库与现有局部 GOP 重编码流程。变速仍属于选区，使用源视频时间；图层不单独变速。
- 保留全屏模糊、区域模糊、PNG 透明度、羽化、逐帧定位、多音轨与工程保存能力；兼容工程 v1/v2。

## 方案

1. 继续为每种效果复制选区：现有选区禁止重叠，无法表达同一时间的多层，不采用。
2. 选区包含独立图层，贴纸与遮罩分别保存变换：采用。图层共用所属选区的速度与锁定状态，分别保存时间、叠放顺序、效果和几何信息。
3. 顶层完全独立轨道、独立遮罩对象加跨层引用：可以表达更复杂的多层共用遮罩，但引入跨选区引用与生命周期管理。本轮没有共用遮罩需求，不采用。

其中第 2 项的遮罩独立移动由用户明确选择；其他实现细节为下文建议，待整体设计审核。

## 时间轴交互

| 区域/操作 | 行为 |
| --- | --- |
| 播放轨左键按下/拖动 | 更新播放位置，保持选区与图层不变 |
| 选区轨左键端点 | 选择该区间；未锁定时拖动端点；不 seek |
| 选区轨左键内部 | 选择该区间；未锁定时整体平移，保持长度；不 seek |
| 选区轨左键空白/锁定区间 | 空白不操作；锁定区间只选中；均不 seek |
| 选区轨右键拖动 | 显示候选范围，松开即创建扣除已有区间后的各个连续片段；无需再点添加 |
| 中键/Alt+左键拖动 | 保留时间轴平移 |

右键规则优先于选中对象的锁定状态：当前选区锁定也可以在其他位置创建。反向拖动将两点排序；左右边界按半开区间处理。按下与松开同一点、全部被覆盖或不足一帧的结果不创建。例：新拖出 [1,8)，已有 [3,5)，生成 [1,3)、[5,8)。多个剩余段都创建，最后选中第一个。

左键调整不会覆盖其他选区：端点和整体移动到邻区边界时停止，且不能越过视频边界。端点最短一帧。整体移动选区时，内部各层的相对时间保持不变；修改端点时，图层活动范围取其时间与选区的交集，不把贴纸时长强制拉伸到选区长度。

创建的新区间默认无效果、速度 1×、未锁定，避免创建选区就自动模糊整屏。原有“锁定片段长度”不再是编辑图层的前提；以明确的选区锁定控制边界与内容，锁定后可浏览，解锁后可编辑。旧工程锁定状态迁移时保留保护。

## 多图层与时间编辑

选区下增加图层列表和可滚动图层时间轨。每个图层一行，能选中、重命名、删除、上下调整顺序；行内拖动片段移动时间、拖端点改变持续时间，也提供起止时间输入。选中图层不会改变播放位置。图层可相互覆盖，数量不设固定上限。

图层时间保存为相对选区入点的秒数。正常编辑不能越过选区，最短一帧。缩短选区时保留原图层记录，超出部分暂不生效；重新扩展可恢复。完全落在选区外的图层仍在列表中标记为“范围外”。**调整入点是裁剪操作，保持各层在源视频上的绝对时刻不变，同时重算相对时间；允许由裁剪产生负的相对起点或超过选区末尾的相对终点。整体移动选区才带动图层在源时间上平移。**例：选区 [1,8)、图层绝对时间 [2,4)，入点改成 3 后图层记录为相对 [-1,1)，实际仅在 [3,4) 生效；入点再恢复到 1 后重新显示完整 [2,4)。验证区分这类保留记录与用户新建/拖动图层的范围限制。

建议保留“确认并锁定片段”的明确确认方式，但草稿按选区保存于内存，点击其他选区或右键创建新选区不会丢失草稿、不会被当前草稿阻断。保存/导出仍要求先确认所有草稿，并在列表标明未确认项。关闭/打开工程沿用未保存提示。无需每增加一个图层就锁定整个选区。

## 贴纸添加和自由变换

素材库改为带缩略图、可拖拽的列表，保留导入与持久复用。图片落点映射到实际视频画面，黑边区域不接收。需要播放位置位于某个可编辑选区内；不在选区内或选区锁定时显示明确提示，不隐式修改选区或播放位置。

新贴纸位于落点，以图片原始比例显示，初始尺寸适配画面且居中于落点；开始时间为当前播放位置，结束时间为 `min(开始+2秒, 选区末尾)`。每次拖放均创建新层，不替换现有层。视频边缘允许贴纸部分超出画面，渲染时裁剪画外部分。

选中贴纸即显示变换框；Ctrl-T 进入自由变换：八个缩放控制点、框内移动、框外旋转，Shift 保持比例，提供位置/宽高/角度数值输入。Enter 提交本次变换，Esc 恢复变换前状态。变换过程中立即更新贴纸显示；播放器定位快捷键不抢占这些按键。本轮自由变换包括移动、缩放、旋转，不包含透视、网格变形或关键帧动画。

## 遮罩与贴纸独立编辑

“添加遮罩”创建新层，矩形、椭圆、套索均可绘制；绘制完成显示“模糊 / 贴纸”用途选择。默认时间从当前播放位置开始到选区末尾，可在图层轨独立调整。

- 模糊：对该层以下已合成画面在遮罩范围内应用模糊，强度与羽化属于该层。
- 贴纸：从素材库指定图片，遮罩成为该层的裁剪范围。支持在现有贴纸层添加/移除遮罩。
- 属性面板提供明确的“编辑贴纸 / 编辑遮罩”目标切换。拖动、缩放、旋转仅修改当前目标。套索移动/缩放需变换完整路径，不能只更新包围框。
- 贴纸按自己的变换生成透明画布；遮罩按独立变换生成覆盖同一视频坐标系的 alpha。最终 alpha 为图片原始 alpha 与遮罩 alpha 的乘积。贴纸与遮罩不相交时该层不可见，仍可切回目标编辑。
- 遮罩形状、旋转、羽化可独立修改；遮罩局部路径与其变换分别保存。移除遮罩恢复完整贴纸，不删除图片。

无需复制共享遮罩对象；每层最多挂一个形状遮罩，多形状效果通过添加多个层实现。每个遮罩层都有自己的时长，暂不增加同层遮罩与图片各自不同的活动时间。

## 数据与渲染

工程格式升级为 v3：Edit 保存选区时间、速度、锁定与 layers；Layer 保存稳定 ID、名称、相对起止时间、类型、图片路径、图片变换、可选 Mask、模糊强度。Mask 保存形状、本地套索路径、独立变换及羽化。列表顺序就是合成顺序，后面的层覆盖前面的层。

读取 v1/v2 时将原 effect 转成一个覆盖完整选区的图层：blur→全屏模糊层，region→模糊遮罩层，image→无额外裁剪的贴纸层，none→空列表。保留原输出几何、速度和锁定状态。v3 保存不再写入两套可分歧的效果来源。

所有时间、比例、位置、角度验证有限值；素材路径按原有相对路径规则保存，并覆盖所有图层的素材保护检查与缺失素材提示。

画布编辑时显示当前时间内各层贴纸及遮罩轮廓，当前编辑目标突出显示。真实模糊、羽化及最终多层合成通过现有“预览当前片段效果”渲染查看；维持现有主画布原画编辑模式，不在本轮引入实时视频模糊解码器。

FFmpeg 按选区内图层顺序合成，以源帧半开区间启用各层。预览与导出共用同一几何/alpha生成逻辑，确保独立旋转、套索变换和透明度一致；先合成图层，再执行选区变速。无改动 GOP 仍直接复制。

## 验收

1. Qt 鼠标测试覆盖播放轨、下轨内部/空白/锁定对象，验证下轨任何操作不发 seek；选择列表的相关路径也不隐式 seek。
2. 右键创建覆盖正向/反向、多个既有区间、完全覆盖、共用边界、零长度和视频边界；结果不重叠、不改旧区间。
3. 端点和移动覆盖选区碰撞、锁定、持续时间保持、图层相对时间与裁剪恢复。
4. 同一区间连续拖入多个素材，各生成独立 2 秒图层；测试末尾截断、画面黑边、锁定与区间外放置提示。
5. Ctrl-T 旋转/缩放/移动、Enter/Esc、贴纸/遮罩目标切换、套索路径完整变换。
6. 实际 FFmpeg 输出像素检验：多层不同时间生效、叠放顺序、PNG alpha、独立移动遮罩前后裁剪位置正确、旋转/套索/羽化以及预览导出一致。
7. v1/v2迁移、v3往返、缺失素材、非有限值、保存/导出素材路径保护。
8. 全量 unittest、compileall；Qt 离屏检查常用与最小窗口尺寸，确认列表滚动和操作按钮可达。
