# Windows 安装包与自定义安装位置

状态：用户已确认，进入实现。延续已选定的 PyInstaller 轻量启动器和按需组件方案。

## 安装包和默认位置

新增 Windows x64 的 `Q-Pixelate-Setup.exe`。使用 Inno Setup 分发已有启动器、发行清单和必要说明。安装向导分别提供「程序安装位置」和「组件安装位置」，创建开始菜单入口，并登记到 Windows 的「已安装的应用」。默认按当前用户安装。

| 目录 | 默认位置 | 内容 |
| --- | --- | --- |
| 程序目录 | `%LOCALAPPDATA%\Programs\Q-Pixelate` | 启动器、发行清单、卸载程序 |
| 组件目录 | `%LOCALAPPDATA%\Q-Pixelate\components` | 基础编辑器、FFmpeg、可选识别环境和模型 |

此前选择的轻量路线作为安装版默认。安装包保持较小，首次启动继续检测和按需安装组件。已有发布地址时支持联网下载，也可从安装包旁边的配套 ZIP 或用户指定的离线包目录安装。另保留直接解压使用的便携版，便携版继续默认在程序同目录存放组件，设置独立于安装版。

## 从设置中更改位置

在「设置 → 环境与组件」显示两个当前路径，提供打开目录及更改位置入口。

- 「更改组件位置」支持把现有组件迁移到可写的新目录。启动器在编辑器退出后执行迁移。复制并验证基础环境、可用的视频工具和已安装组件后，再切换配置。取消、空间不足或校验失败时继续使用旧目录。迁移成功后可由用户选择清理旧组件副本。
- 「更改程序位置」启动安装维护流程，展示新目录并更新开始菜单快捷方式和 Windows 卸载记录。程序迁移复用原组件目录。确认新位置可启动后，可清理旧目录中的程序文件，保留该目录里的用户文件和组件。便携版可以通过关闭程序后移动整套目录，或从设置进入安装向导切换为安装版。

安装版保存稳定的每用户配置，并将程序位置、组件位置和配套 ZIP 来源分别解析。迁移时保留识别设置、外部工具引用、视频工程和贴纸。卸载时默认保留已下载的组件，用户可选择清理软件自己安装的组件文件。共享目录中的其他文件始终保留。

## 验收

- 从安装包首次安装到含中文和空格的自选路径，程序和组件分别置于两个目录。验证开始菜单入口、离线安装、重启和 Windows 卸载记录。
- 通过应用内设置分别更改两个位置，并验证已有模型和 FFmpeg 可以继续使用。验证跨卷组件迁移、错误或取消回退、目标目录有其他文件时的处理，以及快捷方式更新。
- 验证卸载保留策略及已有便携版、源代码启动方式和保存工程的回归行为。
